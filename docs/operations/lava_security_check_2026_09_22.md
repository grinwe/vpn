# Проверка службы безопасности lava.top (сентябрь 2026): документы и доказательства оказания услуг

Контекст: перед выводом средств СБ lava.top запросила (1) где размещены пользовательское соглашение, политика возвратов и политика обработки ПД; (2) доказательства, что клиенты получили оплаченные через lava.top услуги (скриншоты, записи экрана, договоры). Разбор допустимости VPN на платформе — память `reference_lava_top_vpn_policy` (VPN не запрещён, 338 одобренных VPN-карточек).

## 1. Документы

Шаблоны (заполнить реквизиты Исполнителя в квадратных скобках):

- `docs/legal/user_agreement.md` — пользовательское соглашение (публичная оферта);
- `docs/legal/refund_policy.md` — политика возвратов;
- `docs/legal/privacy_policy.md` — политика обработки персональных данных.

Где публиковать (СБ спрашивает именно «на каких ресурсах»):

1. **Посты на нашей странице lava.top** (кабинет → Контент → «Создать пост», по одному документу на пост). Это самое естественное для платформы место: проверяющий ходит по нашему же профилю.
2. **Telegra.ph** — зеркало трёх страниц, чтобы ссылки открывались без регистрации.
3. **Бот, раздел «Помощь»** — ссылки на те же страницы (правка UI, отдельным шагом).

В ответе СБ перечислить все ссылки.

## 3. Что приложить в ответ СБ

1. **Таблица выше** (без внутренних id — оставить контракт lava, дату, сумму, «подписка активна до», «последнее подключение»). Контракты СБ сверит со своими продажами.
2. **Скриншоты админки** по 2–3 клиентам: карточка пользователя → платёж `lava_top` с `external_id` = контракт → подписка активна → устройства с датой последнего подключения и трафиком.
3. **Скриншоты кабинета клиента** (собственный тестовый аккаунт владельца, платежи 19/20): «История» с пополнением «Карта РФ», активная подписка, конфигурация.
4. **Запись экрана сквозного сценария** (самое сильное): мини-апп → «Пополнить» 100 ₽ → СБП → страница lava → оплата → возврат в кабинет → баланс вырос → тариф активен → в VPN-клиенте профиль обновлён и подключение установлено → сайт проверки IP показывает страну нашего сервера. Один ролик 1–2 минуты закрывает «доказательства получения услуги» целиком.
5. **Публичная оферта и политики** — ссылки (раздел 1).
6. Опционально: **договоры/счета хостинг-провайдеров** на серверы, если спросят про инфраструктуру.

## 4. Формулировка для ответа

> Пользовательское соглашение, политика возвратов и политика обработки персональных данных опубликованы: [ссылки на посты lava.top / telegra.ph]; те же документы доступны клиентам в боте, раздел «Помощь».
>
> Услуга — подписка на VPN-сервис, выдаётся автоматически после оплаты: средства зачисляются на баланс личного кабинета в течение 1–2 минут, с баланса ежедневно списывается стоимость активного тарифа, клиент получает конфигурацию для подключения. Прилагаем: (1) сводную таблицу по всем оплатам через lava.top — контракт, дата, сумма, статус подписки и дата последнего подключения клиента; (2) скриншоты нашей панели по нескольким клиентам с привязкой платежа к контракту lava.top; (3) запись экрана полного сценария оплата → зачисление → активация → подключение. Готовы предоставить дополнительные материалы по любому конкретному контракту.
